# Sharpener Node Task 2 - Billing & Tax Calculation Utility

A lightweight Node.js utility for calculating tax, discounts, and itemized billing summaries.

## Features

- **Bill Breakdown**: Calculates discount, taxable base, and final tax amounts.
- **Input Validation**: Ensures valid numeric inputs for prices and rates.
- **Currency Formatter**: Uses `Intl.NumberFormat` for currency representation.
- **Built-in Tests**: Self-contained test suite verifying calculation logic.

## Getting Started

### Prerequisites

- Node.js (version 16 or later)

### Run the script

```bash
node index.js
```

Or using npm:

```bash
npm start
```

### Run tests

```bash
npm test
```
